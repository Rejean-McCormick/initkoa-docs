# 08 — Shared terminology

**Status:** `TARGET_DESIGN`.

**Canonical state:** Framework-governed semantic identities; not external provider Q/P or language labels. **Source custody:** persistent accepted sources/snapshots, not truth validation. **Derived projection:** rebuildable read representation owned by a consumer. **DecisionRecord:** civic state owned by Konnaxion. **Case/Task:** operational state owned by Orgo. **Qualification:** a scoped independent check of exact inputs. **Publication:** approved disclosure to a specific audience. **Activation:** measured host/product lifecycle. **TBD:** a contract that has not been bilaterally adopted.
