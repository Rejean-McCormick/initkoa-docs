## System-level interpretation

A local authoring workspace does not require public Git. Civic decisions do not require semantic compilation. Educational previews do not create Orgo Tasks or write to Moodle. An optional Koali shell does not grant business rights. Source custody and epistemic validation are distinct owner decisions.

The 26 C0 boundaries are **proposed architectural interfaces**, not proof of completed deployment. Read the [source-based status](../SNAPSHOT_RECONCILIATION.md) before making implementation claims.
