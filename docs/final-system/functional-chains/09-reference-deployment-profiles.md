# 09 — Reference operating profiles

**Status:** `TARGET_DESIGN`.

**Offline authoring:** FC-04 with optional FC-03/19/06, no mandatory internet. **Public reader:** FC-05/06 with permitted immutable read releases. **Civic tandem:** FC-07/08/23/14, optionally FC-16/17 on selected host. **Campus:** FC-10/11/14 with optional Orgo or media. **Editorial:** FC-12/13/22 with human approval. **Medical:** FC-20 plus independent clinical governance. **Creative:** FC-21 and optional education imports.

Each profile must define its own platform, latency, storage and recovery targets; no invented universal deployment or service level objective.
