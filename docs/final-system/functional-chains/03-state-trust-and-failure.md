# 03 — State, trust and failure

**Status:** `TARGET_DESIGN`.

Distinct state machines exist for research acquisition, custody, candidate review, semantic build, independent diagnostic qualification, publication permission, derived reads, operational effects, deployment and Space activation. No phase silently implies the next.

Missing identity, invalid profile, wrong digest or unauthorized publication deny by default. Derived views can be rebuilt; owners reconcile operational effects. A rollback of a UI or host artifact cannot erase an Orgo Task, civic DecisionRecord, student record or preserved source. Public audit metadata must avoid private payload disclosure.
