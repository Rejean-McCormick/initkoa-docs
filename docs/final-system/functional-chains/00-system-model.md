# 00 — System model

**Status:** `TARGET_DESIGN`.

The kOA final system is a federation of independently owned capabilities. No global database, mandatory transport bus or compulsory shell exists. Separate epistemic, business and execution authority. Each chain defines actor, owner, input, output, failure and acceptance; use them in composition only where an admitted producer/consumer contract exists.

Local authoring, static reading, civic operations and education can work independently within their own authorization and data lifecycles.
