# 10 — Quality requirements

**Status:** `TARGET_DESIGN`.

Target properties: integrity, reproducible builds and imports, versioned compatibility, least-privilege identity, actual PEP enforcement, protected student/clinical data, idempotent processing, explicit fallback locale, accessible bilingual navigation, offline/local-first where promised, measured degraded state, independent diagnostics and owner-controlled rollback.

Set concrete numerical SLOs only after owners select an environment and measurement basis. Keep publication/custody rights and operator privileges disjoint.
